Everything needed to submit, plus the one field only you can supply.

## The one remaining blocker

**Your institution.** Two places, both clearly marked:

| File | Where |
|---|---|
| `PAPER.md` | line 5, `**[INSTITUTION — FILL THIS IN]**` |
| `paper.tex` | the `\affiliation` macro near the top |

It was left unfilled deliberately. An affiliation is a factual claim about a real
organisation; it appears nowhere in this repository (your earlier
`docs/submission/RESEARCH_PAPER.md` omits it too), so any value would have been
invented. A wrong affiliation on a submitted paper misattributes the work to an
institution that never authorised it, and it is a five-second fix for you.

Everything else below is done.

## Venue decision

**Primary target: arXiv, `cs.LG`.** Chosen because:

- The contribution is a diagnostic and a negative-result analysis. arXiv imposes
  no gatekeeper, establishes priority immediately, and is where the papers this
  one is in conversation with (Dacrema et al., Musgrave et al., Kapoor &
  Narayanan) are read.
- The work is honestly scoped but rests on a single dataset — §3.4 now documents
  *why* that binds. That is a genuine limitation for a main-conference
  submission and no obstacle at all for a preprint.
- A preprint can be submitted to a workshop afterwards; the reverse is harder.

**Follow-on: the NeurIPS ICBINB workshop** ("I Can't Believe It's Not Better"),
which exists specifically for well-explained negative results and rewards
"thorough understanding, transparency, and reproducibility rather than high
performance." This paper's structure — a null result, a power analysis proving it
informative, and two hypotheses the author refuted himself — matches that call
almost line for line.

**Also viable, in rough order of fit:** RecSys reproducibility track; ECML-PKDD
workshops; *PeerJ Computer Science*; *Machine Learning with Applications*; IEEE
Access.

**Not recommended:** NeurIPS / ICML / ACL main tracks. Single dataset, modest
scope. Submitting there wastes a cycle.

### Licence

Recommended: **CC BY 4.0**. It permits the reuse that makes a diagnostic useful —
other people applying the within-query statistic to their own benchmarks — while
requiring attribution.

### Build before uploading

```bash
cd docs/paper
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

**Upload `paper.bbl` along with the source.** arXiv does not reliably run BibTeX
on submissions; without the `.bbl` your references will silently render as
question marks. This is the single most common arXiv build failure.

Files to include in the upload:

```
paper.tex
paper.bbl          <- generated by the build above; NOT optional
figures/fig1_convergence_and_power.pdf
figures/fig2_representation_ablation.pdf
figures/fig3_matching_isolation.pdf
figures/fig4_efficiency_pareto.pdf
figures/fig5_learning_curve.pdf
```

`references.bib` is not needed once `paper.bbl` exists, and the PNG figures are
not needed — the PDFs are the vector versions.

### Abstract for the submission form

arXiv's abstract field is plain text: no markdown, no LaTeX macros. Paste this.

```
Multi-algorithm comparisons are a staple of applied machine learning and are
routinely reported without grouped cross-validation, significance testing, or any
check that the benchmark rewards the capability its name implies. We conduct one
carefully on a public resume-job-description fit benchmark (7,910 pairs over 643
resumes and 351 postings), and report what the care reveals.

Nine classifiers spanning six model families, evaluated under 10-fold
cross-validation grouped by job posting with per-fold leakage controls, converge
into a band 0.031 AUROC wide; after Holm-Bonferroni correction the leading model
is statistically indistinguishable from all four tree ensembles tested. To
establish that this null is informative rather than underpowered, we run the
identical protocol on a synthetic control with a pre-specified generative process
and a known Bayes ceiling, where it separates the same nine models decisively
(Friedman p = 3.7e-9, against 6.5e-6 on the real task). An equal-budget nested
hyper-parameter search moves no model more than +0.0077 AUROC and leaves the
leader separating from fewer rivals, not more.

Changing the representation moves performance roughly twice as far as changing
the algorithm. A probe that never sees the job posting reaches 0.660 AUROC, 87%
of the best model's score, which initially suggested to us that the benchmark's
labels were not relational. Two experiments refute that reading: 80.6% of label
variance is within-resume, and withholding every test resume from training does
not degrade performance.

What survives is a decoupling. Moving to a 1536-dimensional interaction encoding
gains 0.041 pooled AUROC and 0.047 between-resume ranking accuracy, while
within-resume ranking - which cancels resume identity exactly and therefore
isolates matching - changes by -0.009 (p = 0.45). The pooled metric sums two
capabilities, ranking candidates and matching candidates to roles, and moved
because the easier one moved.

We propose the within-query ranking statistic as a routine companion to pooled
metrics for any paired benchmark with a recurring entity: it needs no additional
labels, costs one pass over predictions already computed, and has a fixed null of
0.5. For algorithmic hiring it is the measurement that separates a system that
ranks matches from one that ranks people. We additionally document that no public
resume-fit corpus currently qualifies as an independent replication target, and
give the normalisation procedure that exposes the contamination raw-text hashing
misses.
```

### Comments field

```
10 pages, 5 figures, 8 tables. Code, per-fold results, and figures included.
```

## Pre-submission checklist

- [ ] **Institution filled in** — `PAPER.md` line 5 and the `\affiliation` macro in `paper.tex`
- [ ] `pdflatex + bibtex + pdflatex + pdflatex` runs clean (see caveat below)
- [ ] `paper.bbl` included in the upload
- [ ] All five figure PDFs render in the built document
- [ ] Read the built PDF once end to end — the LaTeX has never been compiled
- [ ] arXiv categories set: `cs.LG` primary, `cs.IR` + `cs.CY` cross-list
- [ ] Licence selected (CC BY 4.0 recommended)

### The LaTeX has not been compiled

No TeX toolchain was available on the machine where `paper.tex` was written. It
passes structural validation — balanced braces and environments, all 10 citations
resolving against `references.bib` with no orphans either way, 31 labels with no
dangling `\ref`, all 5 referenced figures present on disk — but that is not the
same as a clean build. Budget time for one round of minor fixes: a package your
distribution lacks, or float placement.

If your machine has no LaTeX either, [Overleaf](https://overleaf.com) will compile
it in the browser: upload `paper.tex`, `references.bib`, and the `figures/`
directory.

## Venue-specific reformatting

`paper.tex` currently uses the generic `article` class, which arXiv accepts
as-is. The header documents the swap for other venues:

| Venue | Change |
|---|---|
| IEEE conference | `\documentclass[conference]{IEEEtran}`, drop `geometry`, use `\IEEEauthorblockN` |
| IEEE journal / Access | `\documentclass[journal]{IEEEtran}`, same author change |
| ACM (FAccT, RecSys) | `\documentclass[sigconf]{acmart}`, add `\acmConference`, ACM reference format |
| Springer (LNCS) | `\documentclass{llncs}`, `\institute{}` for affiliation |

The two lines to change are marked `% [CLASS]` in the source.
